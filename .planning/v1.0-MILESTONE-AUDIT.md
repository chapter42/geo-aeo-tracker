### Partial Requirements

**AUTH-05: API routes independently verify session cookie (defense-in-depth)**
- proxy.ts intercepts all /api/* paths and returns 401 for unauthenticated requests
- However, `verifySession()` is exported from lib/auth.ts but never imported by any API route handler
- `/api/scrape`, `/api/audit`, `/api/analyze` have zero independent auth checks
- The phase plan reinterpreted AUTH-05 as proxy-only enforcement
- By strict wording ("independently verify"), this is single-layer protection, not defense-in-depth

### Behavioral Gap

**50-prompt cap vs "no limit" requirement:**
- `sovereign-dashboard.tsx` line 901: `[cleaned, ...prev.customPrompts].slice(0, 50)`
- Bulk import counts `added` before calling `onAddCustomPrompt` — doesn't know about the cap
- If user has 45 prompts and imports 10, UI reports "10 toegevoegd" but only 5 are stored
- BULK-01 states "no maximum prompt limit" — the cap exists in the state layer
