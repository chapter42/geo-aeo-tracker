Modify the existing `PromptHubTab` component in `components/dashboard/tabs/prompt-hub-tab.tsx` to add bulk import functionality. Do NOT change the `PromptHubTabProps` interface — reuse `onAddCustomPrompt` for each prompt.

**New state variables (useState):**
- `showBulkImport: boolean` — toggles bulk import textarea visibility (default: false)
- `bulkText: string` — textarea content (default: "")
- `importResult: { added: number; skipped: number } | null` — summary after import (default: null)

**UI changes:**

1. **"Bulk Import" button** — place it next to the existing "Add" button in the `mb-3 flex gap-2` row. Use `bd-chip` class (secondary styling) with `rounded-lg px-4 py-2 text-sm` to match the Add button sizing. The button text should be "Bulk Import" when textarea is hidden, "Cancel" when textarea is shown. Clicking toggles `showBulkImport`, clears `bulkText` and `importResult` when closing.

2. **Textarea** — shown conditionally when `showBulkImport` is true. Place it directly below the input row (before the prompt list). Use a `<textarea>` with class `bd-input w-full rounded-lg px-3 py-2 text-sm` and `rows={6}`. Placeholder text: `"Paste prompts here, one per line..."`. Bind value to `bulkText` state.

3. **"Add All" button** — shown below the textarea when `showBulkImport` is true. Use `bd-btn-primary rounded-lg px-4 py-2 text-sm`. Disabled when `bulkText.trim()` is empty. Clicking triggers the bulk import handler.

4. **Summary message** — shown after import when `importResult` is not null. Display as a `<p>` with class `text-sm text-th-text-accent` below the textarea area. Format: `"{added} van {total} prompts toegevoegd, {skipped} duplicaten overgeslagen"` when there are skipped duplicates. When all are added: `"{added} prompts toegevoegd"`. Auto-clear `importResult` after 5 seconds using `setTimeout` in the handler (clean up with return value if component unmounts — but since this is a simple timeout, a ref is not strictly needed for this small UI).

**Bulk import handler logic (`handleBulkImport` function):**
1. Split `bulkText` by newline (`\n`)
2. Trim each line, filter out empty/whitespace-only lines
3. Deduplicate within the pasted batch itself (keep first occurrence)
4. For each remaining line, check if it already exists in `customPrompts` (case-sensitive match, exact string)
5. Call `onAddCustomPrompt(line)` for each line that is NOT already in `customPrompts`
6. Count `added` (new prompts added) and `skipped` (duplicates found in existing list OR within the batch)
7. Set `importResult` with the counts
8. Clear `bulkText` to empty string
9. If at least one prompt was added, set `showBulkImport` to false after a brief delay (1.5 seconds) so the user can read the summary. Use `setTimeout(() => setShowBulkImport(false), 1500)`.
10. If zero prompts were added (all duplicates), keep the textarea open so user can see the summary and try again.

**Important constraints (from user decisions):**
- NO file upload — textarea only (per user decision)
- NO preview step — prompts are added immediately on click (per user decision)
- NO maximum prompt limit — accept any number of lines (per user decision)
- NO {brand} placeholder validation — users decide themselves (per user decision)
- Lege regels en whitespace automatisch opschonen — geen melding nodig (per user decision)
- Duplicaten stil overslaan — geen foutmelding per duplicaat, wel samenvatting (per user decision)
